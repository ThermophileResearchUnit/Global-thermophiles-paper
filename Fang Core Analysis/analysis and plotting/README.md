## Post-DADA2 Processing and Analysis

DADA2-derived ASV and taxonomy tables were imported into R for downstream processing. Analyses included metadata integration, contamination identification and removal, low-abundance ASV filtering, taxonomic curation, and generation of phyloseq and mctoolsR objects for downstream community analyses.

Downstream workflows included:

- Alpha diversity analyses
- Beta diversity analyses and ordination (PCoA/NMDS)
- Community composition summaries
- Differential abundance analyses (where applicable)
- Taxonomic and ecological visualizations
- Generation of publication-quality figures
