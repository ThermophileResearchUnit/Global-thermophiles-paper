## Post-DADA2 Processing and Analysis

DADA2-derived ASV and taxonomy tables were imported into R for downstream processing. Analyses included runnning decontam to help remove potential contaminants, metadata integration,  ASV table filtering, and diversity and taxonomic comparisons. 
Downstream workflows included:

- Alpha diversity analyses
- Beta diversity analyses and ordination (PCoA/NMDS)
- Community composition summaries
- Differential abundance analyses (where applicable)
- Indicator taxa analysis
- Taxonomic and diversity visualizations
- Generation of figures

also included:
Files used for searching for thermophiles within Antarctic soils (which are from https://link.springer.com/article/10.1007/s00300-025-03372-y)
