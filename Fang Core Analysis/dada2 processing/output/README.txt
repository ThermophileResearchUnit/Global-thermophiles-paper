This directory contains the output files from the dada2 pipeline (see knit .html file in "dada2 processing" for full details. Directory contains files: 
-seqtab_wTax_mctoolsr.txt - which contains a formatted ASV table for mctoolsR (r package)
-seqtabfinal.txt - unformattted ASV table
-tax_final.txt - contains taxonomy of each ASV
-repset.fasta - fasta file containing all sequences for each ASV
